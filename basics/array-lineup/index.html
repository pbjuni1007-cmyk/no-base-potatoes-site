배열은 여러 값을 순서 있게 보관합니다

const orders = ['감자튀김', '음료', '감자전']

배열(Array) 은 여러 값을 순서대로 보관합니다. 배열 안의 값 하나하나를 요소라고 합니다.

요소의 위치 번호인 인덱스는 0부터 시작합니다. length는 요소의 개수이므로 마지막 인덱스는 length - 1입니다.

orders[0] // '감자튀김'
orders.length // 3
orders[orders.length - 1] // '감자전'

하나씩 보고, 조건에 맞는 새 배열을 만듭니다

for...of는 인덱스가 아니라 배열의 요소 값을 순서대로 하나씩 꺼냅니다.

for (const order of orders) {
  console.log(order)
}

filter()는 각 요소가 조건을 통과하는지 확인해 새 배열을 반환합니다. 앞의 함수 글에서 배운 이름 있는 함수를 조건으로 사용해 봅시다.

function isPotatoOrder(order) {
  return order !== '음료'
}

const potatoOrders = orders.filter(isPotatoOrder)

console.log(potatoOrders) // ['감자튀김', '감자전']
console.log(orders) // ['감자튀김', '음료', '감자전']

!==는 두 값의 타입이나 내용이 다르면 true, 같으면 false를 만듭니다. filter()는 요소를 하나씩 isPotatoOrder에 넘겨 true인 요소만 새 배열에 담습니다.

filter()가 원본 배열에서 음료 주문을 직접 지운 것은 아닙니다. 조건에 맞는 요소만 모아 새 줄을 만든 것입니다.

Q1 · 반복에서 꺼내는 것

아래 반복문에서 order가 차례로 받는 것은 무엇일까요?

const orders = ['감자튀김', '음료', '감자전']

for (const order of orders) {
  console.log(order)
}
반복할 값 하나를 고르세요.

Q2 · 위치와 새 목록 연결하기

배열의 시작 위치와 filter 결과를 완성해 봅시다.

배열의 첫 요소 인덱스는 이고, filter()는 조건을 통과한 요소를 담은 배열을 반환합니다.

주문 줄 비유가 맞는 곳과 깨지는 곳

줄 선 주문표는 순서, 주문표 한 장은 요소, 번호표는 인덱스를 떠올리게 합니다. filter()는 조건에 맞는 주문표만 새 줄에 복사해 세우는 일과 비슷합니다.

현실 번호표는 보통 1번부터 시작하지만 JavaScript 배열 인덱스는 0부터 시작합니다. 또한 배열 요소는 종이가 아니라 문자열·숫자·객체처럼 어떤 값도 될 수 있습니다.
