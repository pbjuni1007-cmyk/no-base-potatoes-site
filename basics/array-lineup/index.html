중심 질문: 여러 값을 순서대로 두고 조건에 맞는 값만 어떻게 고를까요?

JavaScript의 Array와 Python의 list는 여러 값을 순서대로 보관하는 각 언어의 자료형입니다. 둘은 비슷한 역할을 하지만 같은 타입은 아닙니다.

  • 요소(element) 는 Array나 list 안에 들어 있는 값 하나입니다.
  • 인덱스(index) 는 요소의 위치 번호이며 0부터 시작합니다.
  • 반복은 요소를 차례로 하나씩 처리하는 일입니다.

감자 식당 신입 알바 세 명의 교육 점수가 [85, 92, 78]이고, 85점 이상인 점수만 고르면 결과는 [85, 92]입니다.

기존 JavaScript에서는 어떻게 썼을까요?

const scores = [85, 92, 78]

function isPassed(score) {
  return score >= 85
}

const passedScores = scores.filter(isPassed)

console.log(scores[0])
console.log(scores.length)
console.log(passedScores)
console.log(scores)

length는 Array의 요소 개수입니다. filter()는 각 요소를 조건 함수에 넣고, 결과가 참인 요소만 모은 새 Array를 반환합니다.

  1. scores[0]은 첫 요소 85를 찾습니다.
  2. scores.length는 요소 개수 3입니다.
  3. filter()는 85, 92, 78을 차례로 isPassed에 전달합니다.
  4. 85 >= 85와 92 >= 85는 참이고, 78 >= 85는 거짓입니다.
  5. 예상 출력은 85, 3, [85, 92], [85, 92, 78]입니다.

마지막 출력처럼 filter()는 원본에서 78을 지우지 않고, 통과한 점수로 새 Array를 만듭니다.

같은 상황을 Python으로 쓰면 어떻게 될까요?

scores = [85, 92, 78]

passed_scores = [score for score in scores if score >= 85]

print(scores[0])
print(len(scores))
print(passed_scores)
print(scores)

리스트 컴프리헨션(list comprehension) 은 기존 값을 차례로 살펴 새 list를 만드는 Python 문법입니다. len()은 요소 개수를 돌려주는 함수입니다.

리스트 컴프리헨션은 각 점수가 85 이상인지 확인해 새 list를 만듭니다. 출력은 JavaScript 예시와 같은 85, 3, [85, 92], [85, 92, 78]이며, 원본 scores도 그대로입니다.

두 언어의 실제 차이

JavaScript Array와 Python list는 생김새와 여러 동작이 비슷하지만 서로 다른 언어에 속한 다른 타입입니다. 요소 개수도 JavaScript는 .length, Python은 len(...)으로 확인합니다.

이 예제에서 새 목록을 만드는 대표 표현도 다릅니다.

  • JavaScript: scores.filter(isPassed)가 새 Array를 반환합니다.
  • Python: [score for score in scores if score >= 85]가 새 list를 만듭니다.

선택 사항 · Python의 filter()는 list가 아니라 이터레이터를 반환합니다. 이 글에서는 결과를 바로 읽기 쉬운 리스트 컴프리헨션만 사용합니다.

흔한 오해 경계

  • 첫 요소의 인덱스는 1이 아니라 0입니다.
  • 인덱스는 위치 번호이고, 요소는 그 위치에 있는 값입니다.
  • JavaScript filter()는 원본을 수정하지 않고 새 Array를 반환합니다.
  • Python 예시는 리스트 컴프리헨션으로 새 list를 만듭니다.

번호 순서대로 줄 선 점수표는 순서와 요소를 떠올리는 데 도움이 됩니다. 다만 현실 번호표는 보통 1번부터 시작하고, 코드의 인덱스는 0부터 시작합니다. 또한 Array와 list에는 점수뿐 아니라 문자열이나 다른 값도 들어갈 수 있습니다.
