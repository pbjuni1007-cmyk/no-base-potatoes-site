중심 질문: 질문의 결과와 실행할 길은 어떻게 연결될까요?

불리언(Boolean) 은 참과 거짓을 나타내는 두 값입니다. 비교식은 두 값을 비교해 불리언 값을 만들고, 조건식은 어떤 코드를 실행할지 판단할 때 쓰는 식입니다. 분기는 조건 결과에 따라 실행 경로를 고르는 일입니다.

감자 식당 신입 알바의 교육 점수가 85점 이상이면 통과, 아니면 다음 기회를 출력한다고 해 봅시다. 점수가 78일 때 비교 결과는 거짓이므로 다음 경로를 선택해야 합니다.

기존 JavaScript에서는 어떻게 썼을까요?

const score = 78
const passed = score >= 85

console.log(passed)

if (passed) {
  console.log('통과')
} else {
  console.log('다음 기회')
}

>=는 왼쪽 값이 오른쪽 값보다 크거나 같은지 비교하는 연산자입니다.

  1. score >= 85는 78 >= 85를 계산합니다.
  2. 결과인 불리언 값 false가 passed에 들어갑니다.
  3. if는 거짓일 때의 else 블록을 실행합니다.
  4. 예상 출력은 차례로 false, 다음 기회입니다.

즉, false는 값, 비교식은 그 값을 만드는 질문, if는 답을 보고 실행할 코드를 고르는 문장입니다.

같은 상황을 Python으로 쓰면 어떻게 될까요?

score = 78
passed = score >= 85

print(passed)

if passed:
    print('통과')
else:
    print('다음 기회')
  1. Python도 78 >= 85를 계산해 거짓을 만듭니다.
  2. 그 값이 passed에 연결됩니다.
  3. if가 else 아래의 코드를 실행합니다.
  4. 예상 출력은 차례로 False, 다음 기회입니다.

Python의 불리언 값은 첫 글자를 대문자로 쓴 True, False입니다. JavaScript의 true, false와 대소문자가 다릅니다.

두 언어의 실제 차이

두 언어 모두 if의 조건 자리에서 값의 진리값을 봅니다. 진리값은 그 값을 조건에서 참처럼 볼지 거짓처럼 볼지 정한 결과입니다. 불리언이 아닌 값도 조건에 들어갈 수 있으며, 참처럼 취급되는 값을 truthy, 거짓처럼 취급되는 값을 falsy라고 부릅니다.

하지만 falsy인 값의 목록은 완전히 같지 않습니다. 예를 들어 빈 목록은 Python에서는 거짓처럼 취급되지만, JavaScript의 빈 배열은 참처럼 취급됩니다.

if ([]) {
  console.log('JavaScript에서는 실행됨')
}
if []:
    print('Python에서는 실행되지 않음')

따라서 한 언어의 truthy·falsy 규칙을 다른 언어에 그대로 옮기면 안 됩니다.

흔한 오해 경계

  • true·false 또는 True·False는 실행 명령이 아니라 값입니다.
  • 비교식이 불리언 값을 만들고, if가 그 결과를 보고 실행 경로를 고릅니다.
  • 0, 빈 문자열처럼 falsy인 값도 실제로 존재하는 유효한 데이터일 수 있습니다.
  • 조건에 값 하나를 바로 넣을 때는 언어별 진리값 규칙을 확인해야 합니다.

주문 레일 비유는 조건 결과에 따라 길이 갈리는 모습을 기억하는 데 도움이 됩니다. 다만 불리언 값이 주문을 직접 옮기지는 않으며, 실제로는 if 문이 실행할 코드 블록을 고릅니다.
