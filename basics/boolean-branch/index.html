true와 false는 실행 명령이 아니라 값입니다

앞의 함수 글에서는 코드를 호출하면 결과를 반환한다는 흐름을 봤습니다. 이번에는 질문을 계산한 결과가 true인지 false인지에 따라 실행할 길을 고릅니다.

불리언(Boolean) 은 true와 false, 두 값만 가집니다. 비교식은 두 값 중 하나를 결과로 만듭니다.

const potatoCount = 3
const canServe = potatoCount >= 2

console.log(canServe) // true

potatoCount >= 2는 “감자가 2개 이상인가?”를 계산하는 조건식입니다. 그 답인 true가 canServe에 들어갑니다.

if는 조건을 보고 실행할 길을 고릅니다

if (canServe) {
  console.log('감자 메뉴를 준비합니다.')
} else {
  console.log('감자 메뉴가 부족합니다.')
}

if는 조건이 참이면 첫 블록을 실행하고, 거짓이면 else 블록을 실행합니다. 이처럼 조건에 따라 실행 경로를 고르는 일을 분기라고 합니다.

정리하면 true는 값, 조건식은 그 값을 만드는 질문, if는 답을 보고 실행할 코드를 고르는 문장입니다.

JavaScript의 조건 자리에는 불리언이 아닌 값도 들어갈 수 있고, 이때 값은 참처럼 또는 거짓처럼 변환됩니다. 이를 truthy와 falsy라고 부릅니다. 지금은 이름만 알아두고, 뒤의 없는 값 글에서 0·false·빈 문자열을 다시 구분합니다.

스스로 확인

Q1 · 질문의 결과 찾기

아래 코드에서 canServe에 저장되는 것은 무엇일까요?

const potatoCount = 3
const canServe = potatoCount >= 2
값의 역할 하나를 고르세요.

Q2 · 값과 실행 연결하기

조건식과 if의 역할을 완성해 봅시다.

조건식은 을 만들고, if는 그 결과를 보고 를 고릅니다.

주문 레일 비유가 맞는 곳과 깨지는 곳

포장 여부 신호가 true이면 포장 레일, false이면 매장 레일로 보내는 장면은 분기를 기억하기 좋습니다.

다만 불리언 값이 주문을 직접 옮기지는 않습니다. 실제 코드에서는 조건식을 평가한 뒤 if 문이 어느 코드 블록을 실행할지 정합니다. 레일이 두 갈래라고 해서 모든 프로그램의 분기가 두 개뿐인 것도 아닙니다.
