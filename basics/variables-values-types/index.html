중심 질문: 이름, 값, 타입은 무엇이 다를까요?

감자 식당 신입 알바가 주문을 코드로 기록한다고 생각해 봅시다.

  • 이름은 값을 나중에 다시 찾을 때 쓰는 표시입니다.
  • 값은 프로그램이 실제로 다루는 데이터입니다.
  • 타입(type) 은 값의 종류입니다. 예를 들어 글자는 문자열, 수량은 숫자입니다.
  • 할당(assignment) 은 이름을 값에 연결하는 일입니다.
  • 재할당은 같은 이름을 다른 값에 다시 연결하는 일입니다.

이름, 값, 타입은 서로 역할이 다릅니다. menu는 이름이고, '감자튀김'은 값이며, 이 값의 타입은 문자열입니다.

기존 JavaScript에서는 어떻게 썼을까요?

const menu = '감자튀김'
let quantity = 2

quantity = 3

console.log(menu)
console.log(quantity)
console.log(typeof menu)
console.log(typeof quantity)

코드는 다음 순서로 읽습니다.

  1. menu에 문자열 값 '감자튀김'을 연결합니다.
  2. quantity에 숫자 값 2를 연결했다가 3으로 재할당합니다.
  3. 예상 출력은 차례로 감자튀김, 3, string, number입니다.

typeof는 JavaScript에서 값의 타입을 문자열로 알려 주는 연산자입니다. const로 선언한 이름은 재할당할 수 없고, let으로 선언한 이름은 재할당할 수 있습니다.

같은 상황을 Python으로 쓰면 어떻게 될까요?

menu = '감자튀김'
quantity = 2

quantity = 3

print(menu)
print(quantity)
print(type(menu))
print(type(quantity))
  1. menu에 '감자튀김', quantity에 2를 연결합니다.
  2. quantity를 3으로 다시 연결합니다.
  3. 예상 출력은 차례로 감자튀김, 3, <class 'str'>, <class 'int'>입니다.

type()은 Python에서 값의 타입을 확인하는 함수입니다. str은 문자열, int는 정수 타입입니다. 두 예시는 같은 메뉴와 수량을 다루지만 타입을 표시하는 모양은 서로 다릅니다.

두 언어의 실제 차이

JavaScript의 const와 let은 이름을 처음 만드는 선언 키워드입니다. const는 그 이름의 재할당을 막고, let은 허용합니다.

Python의 =은 이름을 값에 연결하거나 다시 연결합니다. Python에는 이 예제의 const에 바로 대응하는 선언 키워드가 없습니다.

menu = '감자튀김'
menu = '감자전'

print(menu)
# 감자전

Python에서는 같은 이름을 새 값에 다시 연결할 수 있습니다. 따라서 menu = '감자튀김'을 JavaScript의 const menu와 같다고 읽으면 안 됩니다.

타입 이름도 다릅니다. 같은 글자 값이라도 JavaScript는 string, Python은 str이라고 표시합니다. 숫자 3도 이 예제에서는 JavaScript의 number, Python의 int로 확인됩니다.

흔한 오해 경계

const는 그 이름을 다른 값에 다시 연결하지 못하게 합니다. Python의 일반적인 = 할당에는 같은 제한이 없습니다. 객체의 내부 변경 규칙은 별도의 객체 글에서 다룹니다.

감자 식당의 이름표는 이름, 내용물은 값, 재료 종류는 타입을 떠올리는 데 도움이 됩니다. 다만 실제 이름은 물리적인 통이 아니며, 언어마다 이름을 만들고 다시 연결하는 규칙도 다릅니다.
