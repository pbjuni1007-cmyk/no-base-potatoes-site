오늘 수업에서 꼭 가져가야 할 것

Python 리스트에 있던 점수가 NumPy 배열, Pandas 표와 그래프로 갈 때 각 도구는 무엇을 맡을까요?

기록 담당 감자는 같은 점수를 숫자 배열, 이름 있는 표와 결과 그래프로 나누어 다룹니다.

리스트에서 NumPy 배열로: 숫자 묶음의 모양과 연산을 다룬다

scores = [85, 92, 78]
score_array = np.array(scores)

print(score_array.shape)  # (3,)
print(score_array.dtype)  # 실행 환경에 따라 int64 등으로 표시

NumPy 배열은 차원과 모양, 값의 자료형 정보를 함께 가집니다. 배열의 모든 값에 같은 계산을 표현할 수도 있습니다.

adjusted_array = score_array + 3
print(adjusted_array)  # [88 95 81]

벡터화 연산

Python 반복문을 직접 쓰지 않고 배열의 여러 값에 같은 계산을 표현하는 방식.

벡터화 표현은 계산을 간결하게 만들고 많은 경우 효율적입니다. 하지만 언제나 더 빠른 것은 아닙니다.

배열에서 Pandas DataFrame으로: 값에 행과 열의 뜻을 붙인다

score_table = pd.DataFrame({
    "name": ["민준", "서연", "지우"],
    "team": ["A", "B", "A"],
    "score": score_array,
    "adjusted_score": adjusted_array,
})

DataFrame은 행(가로줄)과 열(세로줄)로 된 표입니다. score_table["score"]처럼 열 하나를 고르면 Series가 됩니다. 인덱스는 각 행을 찾는 라벨이며, 언제나 단순한 행 번호는 아닙니다.

상세 설명

같은 학생 점수를 표와 그래프로 끝까지 연결하기

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

# Step 1: Python 리스트로 원본 값 준비
names = ["민준", "서연", "지우"]
teams = ["A", "B", "A"]
scores = [85, 92, 78]

# Step 2: NumPy 배열로 숫자 묶음을 만들고 3점 보정
score_array = np.array(scores)
adjusted_array = score_array + 3

# Step 3: 원점수와 보정 점수에 이름을 붙인 Pandas 표 만들기
score_table = pd.DataFrame({
    "name": names,
    "team": teams,
    "score": score_array,
    "adjusted_score": adjusted_array,
})

# Step 4: 팀별 보정 점수 평균 집계
team_mean = (
    score_table.groupby("team", as_index=False)["adjusted_score"]
    .mean()
)
print(team_mean)

# Step 5: 집계 결과를 막대그래프로 표현
fig, ax = plt.subplots()
ax.bar(team_mean["team"], team_mean["adjusted_score"])
ax.set_title("Adjusted score average by team")
ax.set_xlabel("Team")
ax.set_ylabel("Adjusted average")
plt.show()

이번 예제에서 각 단계는 다음 일을 맡습니다.

  1. Step 1 — 리스트: Python 기본 문법으로 원본 값을 순서대로 준비합니다.
  2. Step 2 — NumPy 배열: 숫자 묶음의 shape, dtype을 확인하고 배열 전체에 3을 더합니다.
  3. Step 3 — DataFrame: 원점수와 보정 점수에 이름·팀 같은 열의 뜻을 붙입니다.
  4. Step 4 — 그룹 집계: A팀과 B팀으로 나누어 보정 점수 평균을 계산합니다.
  5. Step 5 — 그래프: 계산된 두 평균을 막대 길이로 비교합니다.

출력되는 팀별 평균은 다음과 같습니다.

  team  adjusted_score
0    A            84.5
1    B            95.0

A팀은 (88 + 81) / 2 = 84.5, B팀은 95 / 1 = 95.0입니다. 그래프는 이 이미 계산된 두 값을 그립니다. 평균을 새로 계산하거나 원인을 판단하는 역할까지 그래프가 대신하지는 않습니다.

이 연결은 학습을 위한 한 경로일 뿐 필수 순서는 아닙니다. DataFrame은 리스트나 파일에서 바로 만들 수 있고, Matplotlib도 여러 형태의 데이터를 받을 수 있습니다.
