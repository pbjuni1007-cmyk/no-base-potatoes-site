데이터의 모양이 바뀌면 신경망 구조도 바뀐다

Day 03. 데이터 구조에 맞는 계산 경로 고르기

예정 강의일 · 2026.09.03

오늘 만들 것

같은 감자 연구 배치 P-0901에도 서로 다른 모양의 데이터가 있습니다. 감자 표면은 image, 보관 온도의 변화는 sensor_sequence, 검사원의 기록은 inspection_note에 담깁니다. 오늘은 이 세 입력을 각각 어떤 신경망 구조로 처리할지 판단하는 작은 architecture 선택표를 만듭니다.

왜 필요한가

딥러닝은 하나의 고정된 모양이 아닙니다. 이미지의 가까운 픽셀, 시간 순서가 있는 센서 값, 문장 안 단어의 관계처럼 데이터가 가진 구조가 다르면 유용한 계산 방식도 달라집니다. 유명한 model 이름부터 외우기보다 입력에서 보존해야 할 관계가 무엇인지 먼저 묻는 편이 안전합니다.

전체 흐름과 오늘의 경계

image           → 가까운 위치의 무늬를 반복 탐색 → CNN 후보
sensor_sequence → 앞뒤 순서를 상태에 이어 담기 → RNN·LSTM 후보
inspection_note → 멀리 떨어진 단어 관계도 비교 → Transformer 후보

이 연결은 출발점이지 절대 규칙이 아닙니다. 실제 선택에는 데이터 양, 지연 시간, 메모리, 정확도와 운영 비용이 함께 들어갑니다. 오늘은 대표 구조의 핵심 계산과 한계까지만 다룹니다.

이름이 많아 보여도 오늘의 질문은 하나입니다. “현재 데이터에서 잃지 말아야 할 관계는 무엇인가?”

지난 수업 복습

Day 02에서는 감자의 feature가 forward propagation을 지나 prediction이 되고, prediction과 target의 차이를 loss로 계산했습니다. backpropagation이 각 parameter의 gradient를 구하면 optimizer가 parameter를 update했습니다.

input → forward → prediction → loss → backward → gradient → update

이 루프는 오늘 만날 CNN, RNN과 Transformer에도 적용됩니다. 달라지는 것은 input의 어떤 관계를 활용하도록 계산 경로를 설계했는가입니다. tensor의 shape도 단서가 됩니다. 예를 들어 RGB 이미지 batch는 흔히 (batch, channel, height, width), 센서 순서는 (batch, time, feature)처럼 나타내지만 정확한 순서는 코드와 framework의 계약을 확인해야 합니다.

1. architecture는 학습 전 계산의 틀이다

architecture

문제를 풀기 위한 절차나 규칙의 묶음. 학습 절차와 예측 절차도 algorithm으로 볼 수 있다.

model

선택한 architecture와 학습 절차가 data에서 parameter를 배운 뒤 실제 예측에 사용하는 결과물.

inductive bias

같은 architecture라도 초기값과 training data가 다르면 다른 model이 만들어질 수 있습니다. CNN은 가까운 픽셀 관계와 같은 위치 규칙을 반복해서 쓰도록 설계됐습니다. 이미지에 알맞은 inductive bias의 한 예지만 모든 데이터에 항상 맞지는 않습니다.

2. 이미지에서는 가까운 무늬를 반복해서 찾는다

낯선 말 6개눌러서 뜻 보기
MLP

입력을 주로 일렬의 값으로 받아 fully connected layer를 통과시키는 기본 신경망 구조.

CNN

작은 filter를 여러 위치에 적용해 이미지처럼 격자 구조를 가진 데이터의 local pattern을 찾는 신경망 구조.

convolution

작은 filter를 입력의 여러 위치에 이동시키며 각 위치의 local pattern에 반응하는 값을 계산하는 연산.

feature map

filter가 입력의 여러 위치에서 만든 반응 값을 위치 구조를 유지한 채 모은 결과.

spatial locality

이미지에서 가까운 위치의 값들이 의미 있는 local pattern을 이룬다는 성질.

weight sharing

같은 filter parameter를 입력의 여러 위치에서 반복해 사용하는 방식.

이미지를 일렬로 펼쳐 MLP에 넣어도 계산은 됩니다. 다만 위아래와 좌우의 이웃 관계가 입력 표현에서 드러나지 않고 parameter 수도 커질 수 있습니다. CNN은 작은 filter로 감자 표면의 가장자리나 반점 같은 local pattern을 여러 위치에서 찾습니다. weight sharing 덕분에 같은 무늬 탐지 규칙을 위치마다 새로 배우지 않아도 됩니다.

image → convolution → activation → feature map
      → 필요하면 pooling으로 축소 → classification layer → grade prediction

초기 feature map은 단순한 선·경계에, 더 깊은 층은 학습 결과에 따라 복합적인 모양에 반응할 수 있습니다. 다만 특정 channel 하나를 사람이 정한 의미 하나와 언제나 정확히 대응시키면 안 됩니다.

3. 순서 데이터에서는 이전 정보를 다음 시점으로 넘긴다

낯선 말 4개눌러서 뜻 보기
sequence data

값이 나타난 순서나 시간 간격이 의미에 영향을 주는 데이터.

hidden state

sequence의 앞부분에서 계산한 정보를 다음 시점의 계산으로 넘기는 내부 상태.

RNN

같은 recurrent 계산을 순서대로 반복하며 이전 hidden state와 현재 input을 함께 처리하는 신경망 구조.

LSTM

여러 gate와 cell state로 정보를 남기거나 버리는 흐름을 조절하도록 만든 RNN 계열 구조.

감자 보관 온도를 시간 1 → 시간 2 → 시간 3 순서로 읽는다면 값의 순서를 뒤섞어서는 안 됩니다. RNN은 이전 hidden state를 현재 계산에 전달합니다. LSTM은 무엇을 오래 남기고 무엇을 갱신할지 조절하는 경로를 더해, 기본 RNN보다 긴 관계를 다루기 쉽게 설계했습니다.

아주 긴 sequence에서는 앞쪽 정보가 충분히 전달되지 않을 때가 있습니다. 계산도 시간 순서대로 진행해야 해서 학습 병렬화가 제한됩니다. LSTM이 긴 관계를 무조건 완벽히 기억하거나 모든 sequence 문제의 정답이 되는 것은 아닙니다.

4. 긴 문장에서는 서로 관련 있는 위치를 직접 비교한다

낯선 말 4개눌러서 뜻 보기
attention

현재 계산에 필요한 정보를 고르기 위해 여러 입력 위치의 관련도를 계산하고 그 값들을 가중해 모으는 방식.

self-attention

하나의 sequence 안에서 각 위치가 같은 sequence의 다른 위치들과 관련도를 계산하는 attention.

Transformer

self-attention과 feed-forward layer 등을 중심으로 sequence의 위치 사이 관계를 처리하는 architecture.

residual connection

어떤 layer의 입력을 뒤쪽 layer의 출력 경로에 더해 정보와 gradient가 흐를 우회 경로를 만드는 연결.

검사 기록에서 “반점이 많지만 상처는 아니다”처럼 멀리 떨어진 단어의 관계가 중요할 수 있습니다. self-attention은 각 위치에서 무엇을 찾을지(Query), 어떤 정보를 가졌는지(Key), 전달할 내용은 무엇인지(Value)에 해당하는 표현을 만들고 관련도를 사용해 정보를 모읍니다.

Transformer는 학습할 때 sequence의 여러 위치를 RNN보다 병렬로 계산하기 쉽습니다. 반면 새 token을 하나씩 만드는 autoregressive generation은 출력 순서를 따라야 합니다. 기본 dense self-attention의 계산량과 메모리는 sequence 길이에 대해 제곱으로 증가하므로 긴 입력이 공짜로 처리되는 것은 아닙니다.

residual connection은 입력 정보가 뒤쪽으로 갈 다른 길을 만들어 깊은 network의 optimization을 돕습니다. 이것이 overfitting을 자동으로 없애거나 어떤 깊이에서도 학습 성공을 보장한다는 뜻은 아닙니다.

선택 설명 · 대표 architecture가 확장된 방향

  • Autoencoder: input을 더 작은 latent representation으로 압축한 뒤 다시 복원하도록 학습하는 구조입니다. 이상 탐지나 표현 학습에 쓸 수 있지만, 압축된 값이 사람이 기대한 의미를 자동으로 가진다고 보장되지는 않습니다.
  • Seq2Seq: 입력 sequence를 받아 다른 출력 sequence를 만드는 문제 설정과 구조 계열입니다. 초기에는 RNN encoder·decoder가 널리 쓰였고, 이후 attention과 Transformer가 번역 같은 작업의 중심 구조가 되었습니다.
  • AlexNet: 큰 규모 이미지 분류에서 deep CNN의 가능성을 널리 알린 사례입니다. 역사적 성공이 현재 모든 이미지 문제에서 그대로 최선이라는 뜻은 아닙니다.
  • ResNet: residual connection을 사용해 더 깊은 network의 optimization과 degradation 문제를 완화했습니다. overfitting이나 gradient 문제 전체를 자동으로 해결하는 만능 장치는 아닙니다.
  • BERT: Transformer의 encoder를 중심으로 양쪽 문맥을 사용해 text representation을 사전 학습한 model입니다. 일반적인 autoregressive decoder와 같은 구조로 부르면 안 됩니다. Transformer의 기초가 더 필요하다면 기존 Transformer 글을 이어서 읽어 보세요.

선택 설명 · 더 긴 sequence를 다루려는 최근 방향

기본 dense attention의 제곱 비용을 줄이기 위해 sparse·linear attention, state-space model(상태 공간 모델), mixture-of-experts 같은 여러 연구 방향이 이어지고 있습니다. Kimi Linear도 긴 context의 계산 효율을 목표로 제안된 최근 연구 사례입니다. 이 영역의 구현과 비교 결과는 빠르게 바뀌며, 논문·공식 저장소의 조건을 벗어나 일반적인 우열이나 제품 성능으로 확대하지 않습니다. 입문 수업의 핵심은 특정 최신 이름이 아니라 데이터 관계와 계산 비용을 함께 보는 기준입니다.
