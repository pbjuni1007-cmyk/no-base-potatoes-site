지난 수업 복습

웹페이지를 아이언맨 슈트라고 생각해 봅시다.

  • HTML은 철판, 관절, 버튼 자리를 만드는 뼈대입니다. 이것만 있으면 일단 깡통입니다.
  • CSS는 그 깡통에 빨강·금색을 칠하고 크기와 배치를 다듬어 아이언맨처럼 보이게 합니다.
  • JavaScript는 부스터와 무기처럼 클릭에 반응하고 실제 동작을 만들게 합니다.

한 줄로 줄이면 이렇습니다.

HTML은 무엇이 있는지, CSS는 어떻게 보이는지, JavaScript는 무엇이 일어나는지를 맡습니다.

Vue는 이 셋을 없애는 새 언어가 아닙니다. HTML·CSS·JavaScript로 만든 화면, 즉 UI가 복잡해질 때 데이터와 화면을 연결하고 관리하기 쉽게 도와주는 JavaScript 프레임워크입니다.

이제 아이언 감자 연구소에서 슈트의 기본 제어 시스템을 조립해 봅시다.

오늘 수업에서 꼭 가져가야 할 것

Vue: 자비스식 제어 시스템

JavaScript가 부스터와 무기를 움직인다면, Vue는 슈트의 상태와 화면을 연결하는 자비스식 제어 시스템에 가깝습니다.

감자탄 수가 바뀌면 개발자가 계기판 글자를 직접 고치지 않아도, Vue가 그 값을 사용한 화면을 새 값에 맞춰 갱신합니다. 이 연결을 반응형(Reactivity)이라고 부릅니다.

SFC: 슈트 한 부품의 설계도

SFC(Single-File Component)는 확장자가 .vue인 파일입니다. 화면의 한 기능에 필요한 세 가지를 한 파일 가까이에 둡니다.

낯선 말 3개눌러서 뜻 보기
컴포넌트

화면을 역할별로 나눠 따로 만들고 조립하는 단위.

확장자

.vue처럼 파일 이름 끝에서 파일 종류를 알려주는 부분.

템플릿

화면에 무엇을 보여줄지 적는 HTML 기반 영역.

  • <template>: HTML 기반의 화면 구조
  • <script setup>: JavaScript 상태와 동작
  • <style scoped>: 현재 컴포넌트에 적용할 CSS

즉 SFC는 아이언 감자 한 부품의 구조·기능·외형을 함께 적은 설계도입니다.

ref: 계기판과 연결된 값

상태(State)는 감자탄 수처럼 화면이 기억하고 보여줘야 하는 값입니다. ref()로 상태를 만들면 Vue가 그 값의 사용과 변화를 추적할 수 있습니다.

  • JavaScript에서는 potatoAmmo.value처럼 .value를 붙입니다.
  • 템플릿의 최상위 ref는 potatoAmmo처럼 .value 없이 씁니다.

Vite: 스타크 연구실

Vite는 슈트 부품이 아니라 프로젝트를 실행하고 빌드하는 스타크 연구실입니다.

Vue 프로젝트를 만들고 실행하는 명령은 컴퓨터에 설치된 Node.js 위에서 동작합니다. 이 수업에서는 npm으로 필요한 패키지를 받고 정해진 명령을 실행합니다.

상세 설명

아이언 감자 연구소의 첫 슈트 시험

아래 SFC는 감자탄 세 발을 가진 아이언 감자입니다.

낯선 말 1개눌러서 뜻 보기
함수

여러 동작을 묶어 이름 붙인 실행 절차.

집게손으로 버튼을 누르면 감자탄 하나가 발사되고, 계기판은 세 칸에서 두 칸으로 바뀝니다.

<script setup>
import { ref } from 'vue'

const potatoAmmo = ref(3) // Phase 1: 상태 준비

function firePotato() {
  if (potatoAmmo.value > 0) {
    potatoAmmo.value -= 1 // Phase 4: 값 변경
  }
}
</script>

<template>
  <main>
    <h1>나는 아이언 감자다</h1>
    <!-- Phase 2: 화면 표시 -->
    <p>남은 감자탄: {{ potatoAmmo }}</p>
    <!-- Phase 3: 클릭 감지 -->
    <button @click="firePotato">감자 발사</button>
    <!-- Phase 5: 화면 갱신 -->
    <p v-if="potatoAmmo === 0">감자탄 없음</p>
  </main>
</template>

<style scoped>
button {
  background: gold;
  font-weight: bold;
}
</style>

코드는 다음 순서로 움직입니다.

  1. Phase 1 — 상태 준비: ref(3)이 감자탄 수를 반응형 상태로 만듭니다.
  2. Phase 2 — 화면 표시: {{ potatoAmmo }}가 그 수를 계기판처럼 보여줍니다.
  3. Phase 3 — 클릭 감지: 버튼을 누르면 @click이 firePotato를 실행합니다.
  4. Phase 4 — 값 변경: 함수가 potatoAmmo.value를 줄입니다.
  5. Phase 5 — 화면 갱신: Vue가 숫자와 v-if 문장을 새 상태에 맞춰 갱신합니다.

낯선 말 1개눌러서 뜻 보기
디렉티브

v-로 시작하며 HTML 요소에 Vue 동작을 붙이는 특별한 표시.

  • {{ }}: 값을 글자로 보여주기
  • v-if: 조건에 따라 보여주기
  • v-for: 같은 모양을 반복하기
  • v-bind 또는 :: HTML 속성과 값 연결하기
  • v-on 또는 @: 클릭 같은 사건과 함수 연결하기
  • v-model: 입력값과 상태 연결하기

computed와 watch도 이름만 구분해 둡시다. 새 값을 계산하면 computed, **값이 바뀐 뒤 별도 행동을 하면 watch**입니다.
