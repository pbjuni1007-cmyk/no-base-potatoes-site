오늘 만들 것

감자랜드 AI 고객센터에 질문이 들어오면 규정 문서를 먼저 검색합니다. 찾은 Document와 질문을 ChatClient에 함께 보내고, 모델이 규정에 근거한 답을 만들게 합니다.

왜 필요한가

모델에게 질문만 보내면 문서에 없는 내용도 그럴듯하게 말할 수 있습니다. 오늘은 이 순서만 잡으면 됩니다. 질문 → Document 검색 → 문서+질문을 모델 입력 → 답.

오늘 수업에서는 이 이름들을 모두 만나지만, 예습에서는 RAG의 질문 시점 흐름만 끝까지 따라갑니다. 구조화 출력의 변환 규칙, 임베딩 수학과 평가 지표는 지금 외우지 않아도 됩니다. R-101은 질문에 등장하는 예시 소품일 뿐 필수 선수지식이 아닙니다.

오늘 수업에서 꼭 가져가야 할 것

질문에 맞는 Document를 찾고, 그 문서와 질문을 모델 입력에 함께 넣어 답을 어떻게 만들까?

RAG는 검색 증강 생성(Retrieval-Augmented Generation)의 줄임말입니다. 답을 만들기 전에 관련 문서를 검색해 모델 입력에 함께 넣는 구조입니다.

임베딩과 VectorStore는 문서를 의미가 비슷한 질문으로 검색할 수 있게 준비합니다. 오늘은 숫자가 만들어지는 내부 원리보다, 검색 결과인 Document가 모델 입력으로 들어가 답의 근거가 된다는 관계만 잡습니다.

상세 설명

질문 시점 흐름을 짧은 코드로 따라가기

문서를 미리 검색 가능하게 만드는 준비 작업은 질문 처리와 분리합니다. 아래 코드는 준비가 끝난 VectorStore를 사용해 질문이 들어온 순간만 보여 주는 학습용 Java 조각입니다.

Answer ask(String question) {
    List<Document> documents = vectorStore.similaritySearch(question);
    String context = joinText(documents);
    String answer = chatClient.prompt()
            .user("[규정]\n" + context + "\n\n[질문]\n" + question)
            .call()
            .content();

    return new Answer(answer, sourcesFrom(documents));
}
  1. 앱이 질문으로 Document를 검색합니다.
  2. 검색 결과인 문서 본문과 질문을 한 모델 입력으로 만듭니다.
  3. content()에서 모델 호출이 실행되고 모델 결과인 답을 받습니다.
  4. 앱은 검색된 Document에서 출처를 꺼내 답과 함께 반환합니다.

출처는 모델이 새로 지어내는 문장이 아닙니다. 검색에서 실제로 사용한 Document가 어디서 왔는지 앱이 읽어 붙이는 값입니다. RAG도 답의 정확성을 자동 보증하지는 않습니다. 그래도 모델에 어떤 근거를 넣었는지는 확인할 수 있습니다.

Q2 · 두 결과 구분하기

선택 설명 · 필요할 때 펼쳐보기

선택 실무층 · 수업 중 다시 볼 내용

필수 예습은 여기까지입니다. 아래는 실제 문서를 오래 운영할 때 수업 중 다시 찾아볼 체크입니다.

  • 인덱싱 운영: 문서를 적당한 크기로 나누고 출처 metadata를 붙입니다. 같은 문서를 다시 넣을 때는 중복이 생기지 않도록 재색인 정책을 정합니다.
  • 검색 0건 경계: 관련 Document가 하나도 없으면 근거 없음 응답을 반환하고 모델을 호출하지 않습니다. 필수 정상 경로를 이해한 뒤 적용할 운영 안전장치입니다.
  • 검색 조정: chunk size, top-k와 similarity threshold는 보편 정답이 아니라 문서와 질문으로 실험할 시작값입니다. 필수 코드에 숫자를 고정하지 않은 이유입니다.
  • 출처 추적: source, page, version 같은 metadata는 모델이 아니라 앱이 관리합니다. 누락되면 어느 문서를 썼는지 되짚기 어렵습니다.
  • 응답 계약: grounded 표시는 검색 문서를 입력했다는 앱의 흐름 정보이지 답이 참이라는 보증이 아닙니다.
  • 평가: 골든 세트는 대표 질문, 기대 답과 기대 출처를 모은 확인용 자료입니다. 검색 결과와 생성 답을 나눠 비교합니다.
  • 수업의 다른 갈래: 프롬프트, 구조화 출력, 스트리밍, 고급 RAG와 평가를 수업에서 만나지만 오늘 필수 자가점검에는 넣지 않습니다.
