지난 수업 복습

어제 JavaScript에서는 값에 이름을 붙이고, 배열에 여러 값을 담았습니다. if로 길을 고르고, for로 같은 일을 반복하고, 함수로 한 가지 일을 묶었습니다. 오늘도 비슷한 역할은 이어지지만, 두 언어의 문법과 동작이 일대일로 같다는 뜻은 아닙니다.

오늘 수업에서 꼭 가져가야 할 것

JavaScript에서 이미 봤던 값·조건·반복·함수를 Python에서는 어떤 표지로 읽으면 될까요?

기록 담당 감자는 세 점수를 어떤 Python 흐름으로 하나씩 확인할까요?

왼쪽의 세 감자를 가운데 판정대가 한 명씩 확인합니다. 85, 92인 두 명은 통과하고 78인 한 명은 이번 반환값에 포함되지 않습니다. return passed는 새 리스트 [85, 92]를 함수를 부른 자리로 돌려줍니다. 원래 scores에서 78을 지웠다는 뜻은 아닙니다.

리스트: 여러 값을 순서대로 담는다

scores = [85, 92, 78]

scores라는 이름이 리스트를 가리킵니다. 리스트는 대괄호 안에 값을 순서대로 담고, 첫 번째 값의 위치는 1이 아니라 0부터 셉니다.

리스트

여러 값을 순서대로 담고 내용을 바꿀 수 있는 Python의 자료형.

인덱스

순서가 있는 데이터에서 값의 위치를 나타내는 번호로, Python에서는 0부터 시작한다.

scores[0]은 첫 번째 점수 85입니다. 하지만 모든 점수를 차례대로 읽을 때는 위치 번호를 직접 세기보다 for value in scores:처럼 값 자체를 꺼내는 편이 읽기 쉽습니다.

조건과 반복: : 다음 묶음은 들여쓰기로 표시한다

for value in scores:          # scores에서 점수를 하나씩 꺼낸다
    if value >= 80:           # 현재 점수가 80 이상인지 확인한다
        print(value)          # 조건을 통과한 점수만 출력한다

for가 리스트에서 값을 하나씩 꺼냅니다. if는 현재 값이 80 이상인지 검사합니다. 두 문장 끝의 :는 이제 들여쓴 코드 묶음이 이어진다는 표지입니다.

들여쓰기

줄 앞의 공백을 맞춰 조건문·반복문·함수에 속한 코드 묶음을 표시하는 Python 문법.

들여쓰기는 꾸밈이 아니라 문법입니다. 같은 묶음의 줄은 같은 깊이로 맞춰야 합니다. 이 예제에서 print(value)는 if에 속한 유일한 줄입니다. 앞 공백을 없애거나 if와 같은 깊이로 줄이면 if의 본문이 비어 실행 전에 IndentationError가 납니다.

함수: 입력 이름과 실제 값을 구분한다

def select_passed(values, minimum=80):  # values와 minimum은 입력을 받을 매개변수
    passed = []                         # 결과를 담을 빈 리스트
    return passed                       # 만든 결과를 함수를 부른 자리로 돌려준다

select_passed(scores)                   # scores는 인수, minimum은 기본값 80 사용

def는 함수를 만듭니다. 코드 옆 주석처럼 정의에 적힌 두 이름은 매개변수이고, 호출할 때 넣은 실제 값은 인수입니다. minimum=80처럼 미리 적어 둔 값은 인수를 생략했을 때 쓰는 기본값입니다.

상세 설명

학생 점수에서 통과 점수만 골라내기

# Step 1: 점수 리스트 준비
scores = [85, 92, 78]

# Step 2: 조건에 맞는 점수를 고르는 함수 정의
def select_passed(values, minimum=80):  # 매개변수와 기본값을 정한다
    passed = []                         # 통과 점수를 담을 새 리스트

    # Step 3: 점수를 하나씩 검사해 새 리스트에 추가
    for value in values:                # values에서 점수를 하나씩 꺼낸다
        if value >= minimum:            # 현재 점수가 기준 이상인지 확인한다
            passed.append(value)        # 통과한 점수를 새 리스트에 추가한다

    # Step 4: 완성한 리스트 반환
    return passed                       # 새 리스트를 함수를 부른 자리로 돌려준다

# Step 5: 실제 리스트를 인수로 전달하고 결과 출력
print(select_passed(scores))            # scores를 인수로 넣고 반환값을 출력한다

실행 흐름은 다음과 같습니다.

  1. Step 1 — 값 준비: scores가 [85, 92, 78] 리스트를 가리킵니다.
  2. Step 2 — 함수 정의: Python은 select_passed가 호출될 때 실행할 묶음을 준비합니다.
  3. Step 3 — 반복과 조건: 85, 92, 78을 차례로 검사합니다. 80 이상인 85와 92만 passed에 추가합니다.
  4. Step 4 — 결과 반환: 반복이 모두 끝난 뒤 [85, 92]를 돌려줍니다.
  5. Step 5 — 호출과 출력: scores를 values 자리에 전달하고, 기본값 80을 사용한 결과를 출력합니다.
[85, 92]

return passed가 for 안쪽에 들어가면 첫 번째 값을 검사한 직후 함수가 끝날 수 있습니다. 코드의 뜻은 단어뿐 아니라 들여쓰기 위치로도 달라집니다.

with open(...)은 파일 작업이 끝날 때 닫는 처리를 맡습니다. 클래스는 관련 데이터와 동작을 묶는 설계이고, 상속은 기존 클래스의 특성을 이어받는 문법입니다. 이번 중심 예제에는 넣지 않습니다.

JavaScript 객체와 Python 딕셔너리는 문법과 종류가 다릅니다. 이번 글에서는 둘을 일대일로 연결하지 않습니다.
