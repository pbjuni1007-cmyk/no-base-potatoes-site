오늘 수업에서 꼭 가져가야 할 것

짧은 Java 코드에서 시작점·값·조건을 찾아 결과를 예상할 수 있을까?

오늘 장면은 감자랜드 입구의 키 제한 확인대입니다.

작성한 Java 코드

public class Main {
    public static void main(String[] args) { // 1. 시작점
        int height = 130;                    // 2. 값
        if (height >= 120) {                 // 3. 조건
            System.out.println("탑승 가능");
        }
    }
}

콘솔 출력

탑승 가능

읽을 표지는 세 개뿐입니다.

  1. main — 시작점: 이 콘솔 예제에서 실행이 시작되는 표지입니다.
  2. int height = 130; — 값: 정수를 담을 이름 height를 만들고 처음 값 130을 넣습니다.
  3. if — 조건: height가 120 이상일 때만 {와 } 중괄호 안을 실행합니다.

조건문

참·거짓 결과에 따라 실행할 문장을 고르는 문법.

public static void, String[] args는 이 예제를 표준 형태로 시작하는 선언의 일부이고, System.out.println은 한 줄을 출력합니다. 오늘은 세 표현을 단어별로 분해하지 않습니다.

상세 설명

1. main: 이 예제의 시작 표지

위쪽은 작성한 코드, 탑승 가능은 실행 뒤 콘솔에 나온 결과입니다. 둘은 같은 글자가 아닙니다.

이 콘솔 예제를 실행하면 JVM이 표준 형태의 main을 호출합니다. 긴 선언을 전부 외우지 말고 main이라는 이름부터 찾습니다.

낯선 말 1개눌러서 뜻 보기
JVM

컴파일된 Java 코드를 읽어 실행하는 프로그램.

모든 Java 프로그램을 언제나 사람이 main부터 직접 실행하는 것은 아닙니다. 지금은 수업의 짧은 콘솔 예제에만 적용합니다.

2. int height = 130;: 자료형·이름·값

  • int: 정수를 다루는 자료형
  • height: 값을 다시 사용할 변수 이름
  • 130: 변수를 만들 때 넣는 처음 값

이 한 줄은 정수를 담을 자리 height를 새로 만들면서 처음 값 130을 넣습니다. 종류 → 이름 → 처음 값 순서로 읽습니다.

3. if: 조건을 보고 한 갈래 선택

height는 130이고, 130은 120 이상입니다. 조건 결과가 참이므로 {와 } 중괄호 안의 출력 문장이 실행됩니다. 이 글에서는 한 문장만 있어도 실수를 줄이기 위해 중괄호를 사용합니다.

System.out.println은 글자를 출력하는 코드입니다. 이 예제의 콘솔에는 탑승 가능이 보입니다.
