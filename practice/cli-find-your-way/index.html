내가 어디 있는지 먼저 확인하기

CLI 01 · 이동하기 전에 현재 위치부터 읽기

CLI 01 · 터미널과 CLI · 로컬 실습

표준 환경 · macOS · Terminal · zsh · VS Code · Git 2.28+

오늘의 미션

macOS의 기본 Terminal을 열고, 현재 위치를 확인한 뒤 버려도 되는 nobase-practice/cli-find-your-way 폴더로 이동합니다. 마지막에는 pwd와 ls -la의 출력만 보고도 “지금 어디에 있고 무엇이 있는지” 설명할 수 있어야 합니다.

시작 상태와 안전선

이 실습의 표준 환경은 macOS · Terminal · zsh · VS Code · Git 2.28 이상입니다. Terminal은 명령을 입력하는 앱이고, zsh는 그 명령을 해석하는 셸(shell)입니다.

먼저 도구가 준비됐는지 한 가지씩 확인합니다. --version은 설치된 도구의 버전을 보여 달라는 옵션입니다.

이번 한 줄에서는 설치된 zsh의 버전을 확인합니다.

zsh --version

zsh 5...처럼 버전 정보가 나타납니다. 오류가 나오면 다음 명령을 입력하지 말고, 오류 문장 전체와 macOS 버전을 확인합니다.

이번 한 줄에서는 설치된 Git의 버전을 확인합니다.

git --version

git version 2...처럼 버전 정보가 나타납니다. 버전이 2.28.0보다 낮거나 오류가 나오면 다음 명령을 입력하지 말고, 현재 출력을 복사해 표준 환경과 비교합니다.

이제 이 글만을 위한 새 연습 공간을 만듭니다. 안전 표식(sentinel file) 은 “이 글에서 새로 만든, 버려도 되는 실습 폴더”임을 확인하는 빈 파일입니다. 같은 이름의 경로가 이미 보이면 그 경로를 실습 폴더로 사용하거나 수정하지 않습니다.

mkdir은 폴더를 만드는 명령입니다. -p는 상위 폴더가 없어도 함께 만들고, nobase-practice가 이미 있으면 그대로 두는 옵션입니다. 이번 한 줄에서는 공통 연습 폴더를 준비합니다.

mkdir -p ~/nobase-practice

성공하면 아무 글자도 나타나지 않습니다. 오류가 나오면 다음 명령을 입력하지 말고, 경로 철자와 오류 문장 전체를 확인합니다.

cd는 현재 작업 디렉터리를 바꾸는 명령입니다. 이번 한 줄에서는 공통 연습 폴더로 이동합니다.

cd ~/nobase-practice

성공하면 아무 글자도 나타나지 않습니다. 오류가 나오면 다음 명령을 입력하지 말고, 방금 만든 경로의 철자와 오류 문장을 확인합니다.

ls는 현재 폴더에 있는 이름을 보여 주는 명령입니다. 이번 한 줄에서는 같은 이름의 실습 경로가 이미 있는지 확인합니다.

ls

폴더가 비어 있으면 아무 이름도 나타나지 않을 수 있습니다. 출력에 cli-find-your-way가 보이면 여기서 멈추고 다음 명령을 입력하지 않습니다. 기존 경로는 사용하거나 수정하지 말고, 현재 ls 출력을 보존해 어떤 경로인지 확인합니다.

이번 한 줄에서는 이 글 전용 폴더를 새로 만듭니다.

mkdir cli-find-your-way

성공하면 아무 글자도 나타나지 않습니다. File exists를 포함한 오류가 나오면 다음 명령을 입력하지 말고, 기존 경로가 생긴 이유를 확인합니다.

이번 한 줄에서는 방금 만든 글 전용 폴더로 이동합니다.

cd cli-find-your-way

성공하면 아무 글자도 나타나지 않습니다. 오류가 나오면 다음 명령을 입력하지 말고, 앞 단계의 mkdir 오류 여부와 폴더 이름의 철자를 확인합니다.

touch는 파일이 없을 때 빈 파일을 만드는 명령입니다. 이번 한 줄에서는 글 전용 폴더에 안전 표식을 만듭니다.

touch .nobase-practice-root

성공하면 아무 글자도 나타나지 않습니다. 오류가 나오면 다음 명령을 입력하지 말고, 현재까지 보인 오류와 폴더 이름을 확인합니다.

pwd는 현재 작업 디렉터리의 전체 경로를 보여 주는 명령입니다. 이번 한 줄에서는 올바른 글 전용 폴더에 들어왔는지 확인합니다.

pwd

출력의 끝이 /nobase-practice/cli-find-your-way로 나타납니다. 다르면 다음 명령을 입력하지 말고, 출력된 현재 위치와 앞서 입력한 cd를 확인합니다.

ls -la의 -l은 자세한 정보를, -a는 이름이 점(.)으로 시작하는 숨김 파일까지 보여 주는 옵션입니다. 이번 한 줄에서는 안전 표식이 실제로 생겼는지 확인합니다.

ls -la

여러 줄의 목록에 .nobase-practice-root가 나타납니다. 보이지 않거나 오류가 나오면 다음 명령을 입력하지 말고, pwd의 위치와 touch 단계의 오류 여부를 확인합니다. 실제 프로젝트나 홈 폴더 전체를 이동·삭제 대상으로 사용하지 않습니다.

처음 만나는 말

  • CLI(Command-Line Interface): 글자로 명령을 입력하고 글자로 결과를 받는 사용 방식입니다.
  • 프롬프트(prompt): 셸이 명령을 받을 준비가 됐음을 보여 주는 표시입니다.
  • 현재 작업 디렉터리: 지금 입력하는 명령이 기준으로 삼는 폴더입니다.
  • 경로(path): 파일이나 폴더의 위치를 나타내는 주소입니다.
  • 절대 경로: /Users/...처럼 시작점부터 전부 적은 경로입니다.
  • 상대 경로: 현재 위치를 기준으로 적은 경로입니다. ..는 상위 폴더입니다.
  • 숨김 파일: 이름이 점(.)으로 시작해 보통의 ls 목록에는 나오지 않는 파일입니다.

명령을 직접 입력하기

1. 현재 위치와 파일 확인

이동하기 전에는 현재 상태부터 읽습니다. 이번 한 줄에서는 현재 위치를 다시 확인합니다.

pwd

/nobase-practice/cli-find-your-way로 끝나는 전체 경로가 나타납니다. 다르면 다음 명령을 입력하지 말고, 현재 경로의 마지막 폴더 이름을 확인합니다.

이번 한 줄에서는 보통 파일과 폴더의 이름을 확인합니다.

ls

안전 표식은 숨김 파일이라 아무 이름도 나타나지 않을 수 있습니다. 오류가 나오면 다음 명령을 입력하지 말고, 바로 앞의 pwd 출력을 확인합니다.

이번 한 줄에서는 숨김 파일을 포함한 자세한 목록을 확인합니다.

ls -la

목록에 .nobase-practice-root가 나타납니다. 사용자 이름과 날짜는 컴퓨터마다 달라질 수 있습니다. 안전 표식이 없다면 다음 명령을 입력하지 말고 현재 위치를 확인합니다.

2. 상대 경로로 이동

..는 현재 위치의 상위 폴더를 뜻합니다. 이번 한 줄에서는 상위 nobase-practice 폴더로 이동합니다.

cd ..

성공하면 아무 글자도 나타나지 않습니다. 오류가 나오면 다음 명령을 입력하지 말고 오류 문장을 확인합니다.

이번 한 줄에서는 이동한 현재 위치를 확인합니다.

pwd

출력의 끝이 /nobase-practice로 나타납니다. 다르면 다음 명령을 입력하지 말고, 출력된 위치를 확인합니다.

이번 한 줄에서는 현재 위치에서 보이는 폴더 이름을 확인합니다.

ls

목록에 cli-find-your-way가 나타납니다. 보이지 않으면 다음 명령을 입력하지 말고, pwd 출력과 폴더 이름의 철자를 확인합니다.

이번 한 줄에서는 현재 위치를 기준으로 글 전용 폴더에 들어갑니다.

cd cli-find-your-way

성공하면 아무 글자도 나타나지 않습니다. 오류가 나오면 다음 명령을 입력하지 말고, 바로 앞의 ls 목록과 입력한 이름을 비교합니다.

이번 한 줄에서는 상대 경로 이동이 끝난 위치를 확인합니다.

pwd

출력의 끝이 /nobase-practice/cli-find-your-way로 나타납니다. 다르면 다음 단계로 가지 말고 현재 경로를 확인합니다.

3. 절대 경로로 돌아오기

~는 현재 사용자의 홈 폴더를 뜻합니다. 이번 한 줄에서는 홈 폴더부터 시작하는 경로를 적어 글 전용 폴더로 이동합니다.

cd ~/nobase-practice/cli-find-your-way

성공하면 아무 글자도 나타나지 않습니다. 오류가 나오면 다음 명령을 입력하지 말고 경로의 각 폴더 이름을 확인합니다.

이번 한 줄에서는 절대 경로로 이동한 현재 위치를 확인합니다.

pwd

출력은 /Users/사용자이름/nobase-practice/cli-find-your-way 모양입니다. 사용자 이름 부분은 사람마다 다릅니다. 끝부분이 다르면 다음 명령을 입력하지 않습니다.

이번 한 줄에서는 이 위치의 안전 표식을 확인합니다.

ls -la

목록에 .nobase-practice-root가 나타납니다. 보이지 않으면 다음 단계로 가지 말고, 현재 pwd와 목록을 다시 확인합니다.

출력에서 확인할 것

명령이 오류 없이 끝났다는 사실만 보지 말고 다음 세 가지를 읽습니다.

  1. pwd의 끝이 /nobase-practice/cli-find-your-way인가?
  2. ls -la에 .nobase-practice-root가 있는가?
  3. cd .. 전후로 pwd의 마지막 폴더 이름이 어떻게 달라졌는가?

정상 흐름 완료

이번 한 줄에서는 최종 현재 위치를 확인합니다.

pwd

출력의 끝이 /nobase-practice/cli-find-your-way로 나타납니다. 다르면 완료가 아니므로 다음 명령을 입력하지 말고 현재 위치부터 복구합니다.

이번 한 줄에서는 최종 폴더의 숨김 파일까지 확인합니다.

ls -la

목록에 .nobase-practice-root가 나타나면 정상 흐름을 완료한 것입니다. 보이지 않으면 완료로 표시하지 말고 현재 위치와 준비 단계를 확인합니다.

대표 실패와 복구

존재하지 않는 폴더로 이동해 오류를 한 번 읽어 봅니다. 이번 한 줄에서는 일부러 없는 폴더 이름으로 이동을 시도합니다.

cd folder-that-does-not-exist

zsh는 no such file or directory를 포함한 메시지를 보여 줍니다. 이 실패는 현재 위치를 바꾸지 않습니다. 다른 cd를 추측해서 입력하지 말고 현재 위치부터 확인합니다.

이번 한 줄에서는 실패 뒤에도 현재 위치가 그대로인지 확인합니다.

pwd

출력의 끝이 /nobase-practice/cli-find-your-way라면 위치가 그대로입니다. 다르면 다음 명령을 입력하지 말고 출력된 경로를 확인합니다.

이번 한 줄에서는 안전 표식이 남아 있는지 확인합니다.

ls -la

목록에 .nobase-practice-root가 나타나면 복구 확인이 끝났습니다. 보이지 않으면 실습을 멈추고 현재 경로를 다시 확인합니다.

완료 확인

먼저 실행 전 결과를 예측합니다. “현재 경로의 마지막 이름은 무엇이고, ls -la에 안전 표식이 보일까?”를 말합니다.

이번 한 줄에서는 예측한 현재 경로를 확인합니다.

pwd

예측한 경로가 한 줄로 나타납니다. 예상과 다르면 다음 명령을 입력하지 말고, 어느 폴더에서 달라졌는지 설명합니다.

이번 한 줄에서는 예측한 안전 표식을 확인합니다.

ls -la

출력에서 .nobase-practice-root를 직접 가리켜 설명합니다. macOS가 만든 다른 숨김 파일이 있을 수 있으므로 숨김 파일의 총개수는 완료 기준으로 사용하지 않습니다.

힌트 없는 변형 과제: 상위 폴더로 한 번 이동한 뒤, 현재 위치에서 보이는 이름만 이용해 cli-find-your-way로 돌아오세요. 마지막에는 pwd와 안전 표식으로 결과를 증명합니다.

변형 과제 정답 확인하기

  1. 이번 한 줄에서는 상위 폴더로 이동합니다.

    cd ..

    성공하면 아무 글자도 나타나지 않습니다. 오류가 나오면 다음 번호의 명령을 입력하지 말고 오류 문장을 확인합니다.

  2. 이번 한 줄에서는 상위 폴더에 보이는 이름을 확인합니다.

    ls

    cli-find-your-way가 나타납니다. 보이지 않으면 다음 번호의 명령을 입력하지 말고 현재 위치를 확인합니다.

  3. 이번 한 줄에서는 확인한 이름으로 글 전용 폴더에 들어갑니다.

    cd cli-find-your-way

    성공하면 아무 글자도 나타나지 않습니다. 오류가 나오면 다음 번호의 명령을 입력하지 말고 앞의 ls 결과와 철자를 비교합니다.

  4. 이번 한 줄에서는 돌아온 현재 위치를 확인합니다.

    pwd

    출력의 끝이 /nobase-practice/cli-find-your-way로 나타납니다. 다르면 다음 번호의 명령을 입력하지 않습니다.

  5. 이번 한 줄에서는 안전 표식을 확인합니다.

    ls -la

    목록에 .nobase-practice-root가 나타나면 변형 과제를 완료한 것입니다.

더 해볼 사람만

man은 macOS에 설치된 명령 설명서를 여는 명령입니다. 이번 한 줄에서는 pwd 설명서를 엽니다.

man pwd

pwd의 설명서 화면이 나타납니다. q를 누르면 Terminal로 돌아옵니다.

이번 한 줄에서는 ls 설명서를 엽니다.

man ls

ls와 옵션 설명이 나타납니다. q를 누르면 Terminal로 돌아옵니다.

이번 한 줄에서는 cd 설명서를 엽니다.

man cd

cd의 설명서 화면이 나타납니다. q를 누르면 Terminal로 돌아옵니다.

Q1 · 이동 전 상태 확인

현재 위치를 모르는 상태에서 가장 먼저 입력할 명령은 무엇일까요?

$ _____
/Users/me/nobase-practice/cli-find-your-way
출력이 현재 작업 디렉터리인 명령을 고르세요.
